# JusfemIA — Prototipo

Prototipo interactivo de JusfemIA (asistencia jurídica con enfoque de género),
exportado desde Claude Design y servido como sitio estático.

- `public/index.html` — prototipo v1 (raíz, `/`)
- `public/prototipo.html` — prototipo v2 (`/prototipo`)
- `public/documentacion.html` — documentación de componentes (`/documentacion`)
- `public/inicio.html` — índice con enlaces a ambos (`/inicio`)
- `public/UI/` — prototipo con la marca aplicada (`/UI`), logo SVG y PDF incluidos
- `public/mobile/` — el prototipo responsive dentro de un marco de iPhone (`/mobile`)
- `public/support.js` — runtime de Claude Design (carga React 18 desde unpkg)

Deploy: sitio estático en Vercel, sin build. Ver `vercel.json`.
