# JusfemIA — Prototipo

Prototipo interactivo de JusfemIA (asistencia jurídica con enfoque de género),
exportado desde Claude Design y servido como sitio estático.

- `public/index.html` — prototipo (runtime `x-dc`)
- `public/support.js` — runtime de Claude Design (carga React 18 desde unpkg)

Deploy: sitio estático en Vercel, sin build. Ver `vercel.json`.
